# AGENTS.md — правила работы с этим репозиторием

Прочитай этот файл полностью до начала любой работы. Он определяет, что здесь истина, а что — история.

## Что это

VPN Tunnel Enforcer — Windows-клиент (Electron 44 + React + TypeScript, sing-box + Wintun) для изоляции трафика и обхода блокировок. Код — в `vpn-tunnel-enforcer/`; среда разработки требует Node.js >=22.13.0.

## Иерархия источников истины (сверху вниз)

1. **`docs/01…03-ТЗ-*.md`** — нормативное техническое задание (3 тома). Требования обязательны.
2. **`docs/04-приёмочные-тесты/`** — критерии готовности: 139 тестов `AT-<WP>-<NNN>` + методология. Задача «готова», когда соответствующие AT выполнимы и зелёные.
3. **`docs-factory8090/06-ТЗ-исправление-и-развитие.md`** — план работ: рабочие пакеты WP-0…WP-12 с привязкой к находкам аудита.
4. **`docs-factory8090/00-журнал-аудита.md`** — статусы находок F-001…F-210 (подтверждена / частично / опровергнута). Опровергнутые не исправлять.
5. **`docs-factory8090/01…05` (обзор, фичи, контейнеры, компоненты, открытые вопросы)** — исторические исследования и планы. **НЕ норматив.** Ничего оттуда не реализовывать и не «исправлять» без явной команды.
6. **Решения владельца по открытым вопросам приняты** и зафиксированы в разделе 10 ТЗ-06 (`docs-factory8090/06-…md`) и в статусах реестра `docs-factory8090/05-открытые-вопросы.md`. Перед началом WP сверяться с разделом 10. Открыт только вопрос подписи кода (раздел 10.8) — его не решать самостоятельно, спросить.

## Правила (не отклоняться)

- Работать по рабочим пакетам WP. Рекомендуемый порядок пакетов — в `docs/README.md` («Рекомендуемый порядок реализации рабочих пакетов»); первым идёт миграция Electron 42→44 из WP-11 (дедлайн 20.10.2026). Перед задачей прочитать набор тестов своего WP в `docs/04-приёмочные-тесты/` и соответствующий раздел ТЗ.
- Расхождение кода с ТЗ — **не исправлять молча**: записать, предложить, спросить.
- Нормативные документы (`docs/`) не править без явного запроса в задаче.
- Плановые функции (mihomo, AmneziaWG, процессный монитор, изоляция аккаунтов) — только WP-12, за фичефлагами, лабораторные критерии в `13-WP-12-плановые-функции.md`. Не включать в production.
- Безопасность важнее доступности: не доказано безопасным → блокировать/пометить «не проверено», не сообщать об успехе.
- Коммитить осмысленными атомарными коммитами на русском/английском по принятому стилю (`docs:`, `fix:`, `chore:`…). Автор: Vladimir Sakharov <newnout6@gmail.com>.

## Definition of Done (перед коммитом)

```bash
cd vpn-tunnel-enforcer
npm run typecheck        # без ошибок
npm test                 # 100% зелёные
python3 ../docs/04-приёмочные-тесты/traceability/check-coverage.py   # exit 0
```

Плюс: затронутые находки F и критерии AC учтены; новые сущности имеют тесты с трассировкой по образцу `AT-*`.
