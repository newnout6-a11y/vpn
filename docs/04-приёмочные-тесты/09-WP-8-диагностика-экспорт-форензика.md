### AT-08-001: Диагностический ZIP — ноль секретов (двойной оракул)
**Трассировка:** AC-DIAG-EXP-001…005, F-004, F-113, WP-8, WP-1 · **Уровень:** L3 · **Тип:** security, dual-oracle
**Шаги:**
1. Прогнать полный цикл с `FAKE-` секретами, абсолютными путями пользователя, реальными IP. Сформировать диагностический ZIP.
2. Оракул 1: сканер по словарю секрето-образных паттернов. Оракул 2: ручная выборка 20 случайных файлов архива.
**Оракул (PASS, если все условия):**
- Оба оракула: 0 вхождений секретов, токенов, приватных ключей, немаскированных user/account paths и реального IP.
- Единый redactor-контекст: одинаковое значение замаскировано одинаково во всех файлах архива.
- Версия схемы диагностики присутствует в манифесте архива.

### AT-08-005: pktmon — явный opt-in и границы
**Трассировка:** AC-DIAG-FOR-005, F-117, WP-8 · **Уровень:** L3 · **Тип:** security, UX-contract
**Шаги:**
1. Попытаться включить полный захват без согласия; затем дать согласие.
**Оракул (PASS, если все условия):**
- `--pkt-size 0` (полный payload) применяется только после явного opt-in с текстом предупреждения; по умолчанию захват только заголовков.
- Остановка захвата всегда возвращает pktmon в исходное состояние (`pktmon status` до/после идентичен).

### AT-08-006: Идемпотентность установки/удаления диагностики
