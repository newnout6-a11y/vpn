# WP-10. Планировщик, ротация, AutoPilot и адаптивный обход — набор тестов

**Покрывает:** F-122…F-129, F-150, F-156; REQ-AUTO-*, REQ-CONN-ADAPT-*, AC-AUTO-001…003, AC-AUTO-SCH-001…006, AC-AUTO-ROT-001…005, AC-AUTO-AP-001…005, AC-CONN-ADAPT-001…006.

---

### AT-10-001: DST и таймзоны планировщика
**Трассировка:** AC-AUTO-SCH-001…003, F-122, WP-10 · **Уровень:** L1 · **Тип:** property-based, boundary
**Фикстуры:** зоны Europe/Moscow (фиксированный offset), America/New_York (DST), Australia/Lord_Howe (30-мин DST).
**Шаги:**
1. Расписания: ежедневно 02:30 (впадает в DST-gap), 01:30 (дублируется при fall-back), еженедельные, через полночь.
2. fast-check над 10 000 случайных instant вокруг переходов.
**Оракул (PASS, если все условия):**
- Каждое расписание срабатывает по документированному правилу: для несуществующего локального времени — сдвиг/пропуск по политике; для двойного — ровно одно срабатывание или оба по политике, но детерминированно.
- Ни одно расписание не срабатывает дважды за один мгновенный момент; instant/zone правила не зависят от системной зоны машины теста (переключение TZ ОС между прогонами не меняет результат).

### AT-10-002: Окна через полночь и пересечения
**Трассировка:** AC-AUTO-SCH-004…006, F-123, WP-10 · **Уровень:** L1 · **Тип:** model-based, boundary
**Шаги:**
1. Окна 23:00–02:00, пересекающиеся расписания, расписание с длительностью 0 и 24ч.
**Оракул (PASS, если все условия):**
- Семантика overnight-окна соответствует спецификации; пересечения обработаны согласно overlap policy (skip/queue/merge) — каждый исход детерминирован и залогирован.

### AT-10-003: Одновременные ручное действие + расписание + ротация
**Трассировка:** F-124, WP-10, WP-0 · **Уровень:** L2 · **Тип:** race, model-based
**Шаги:**
1. С seeded-таймлайном совместить: ручной connect, срабатывание расписания, ротацию профиля — в одну секунду. 200 прогонов.
**Оракул (PASS, если все условия):**
- Lifecycle lock/priority выбирает ровно одного победителя согласно документированному приоритету; проигравшие получают типизированный отказ/отложены.
- Никогда не существует двух одновременных попыток подключения (инвариант координатора); итоговое состояние объяснимо из журнала.

### AT-10-004: Health-before-commit ротации
**Трассировка:** AC-AUTO-ROT-001…005, F-125, WP-10 · **Уровень:** L2 · **Тип:** fault injection
**Шаги:**
1. Ротация на профиль с: (a) мёртвым сервером, (b) истёкшим ключом, (c) handshake timeout.
**Оракул (PASS, если все условия):**
- Переключение выполняется только после успешного health/connect; при отказе остаётся прежний рабочий профиль (проверка egress непрерывности) либо безопасное отключённое состояние с явным статусом.
- Событие ротации содержит причину, проверенный профиль и исход.

### AT-10-005: Чужой туннель
**Трассировка:** F-126, WP-10 · **Уровень:** L3 · **Тип:** negative, compatibility
**Среда:** активный сторонний VPN (фикстура OpenVPN/WireGuard-туннель).
**Оракул (PASS, если все условия):**
- Автоматика обнаруживает чужой туннель и следует политике (отложить/отказ) с понятным статусом; нет «борьбы» маршрутами: состояние сети стабильно 10 мин наблюдения.

### AT-10-006: Адаптивный обход — стабильность 2-из-3
**Трассировка:** AC-CONN-ADAPT-001…006, F-127, WP-10 · **Уровень:** L2 · **Тип:** chaos, property-based
**Шаги:**
1. Пробирки DPI-блокировок: последовательности успех/неудача, включая флапающие (успех, успех, сбой, успех…).
**Оракул (PASS, если все условия):**
- Смена профиля обхода коммитится только при ≥ 2 из 3 успешных проб; флапающие пробы не вызывают осцилляции (гистерезис: не более 1 смены профиля за окно 5 мин при стабильной сети).
- Отмена адаптивного цикла пользователем отматывает частичные изменения.

### AT-10-007: Инвалидация fingerprint профиля
**Трассировка:** F-128, WP-10 · **Уровень:** L2 · **Тип:** metamorphic
**Шаги:**
1. Успешный адаптивный выбор → изменить параметры сервера на стороне фикстуры (порт, fingerprint) → следующий цикл.
**Оракул (PASS, если все условия):**
- Кэшированное решение инвалидировано при смене полного fingerprint профиля; повторное зондирование выполнено до использования.

### AT-10-008: Матрица событий AutoPilot
**Трассировка:** AC-AUTO-AP-001…005, F-129, WP-10 · **Уровень:** L2 · **Тип:** contract matrix
**Шаги:**
1. Подать каждое определённое событие (запуск приложения из списка, сеть Wi-Fi из списка, время) и неопределённое событие.
**Оракул (PASS, если все условия):**
- Реакция только на определённые события и только в заявленной границе; неизвестные события игнорируются с записью в журнал; AutoPilot использует общего координатора (никаких параллельных lifecycle).

### AT-10-009: Скрытая страница и поллинг автоматики
**Трассировка:** F-156, WP-10 · **Уровень:** L3 · **Тип:** performance
**Оракул (PASS, если все условия):**
- В свёрнутом состоянии тики планировщика продолжаются (срабатывания не пропущены за 2 ч), а UI-поллинг снижен; при восстановлении окна нет catch-up шторма.

### AT-10-010: Миграция legacy `stealthMode` — только после решения владельца
**Трассировка:** F-150, WP-10 · **Уровень:** L1/L2 · **Тип:** contract
**Оракул (PASS, если все условия):**
- Без зафиксированного решения владельца настройка не мигрируется и не удаляется; наличие legacy-ключа отражается в диагностике как «ожидает решения».

### AT-10-011: Soak-ротация 24 часа
**Трассировка:** AC-AUTO-ROT-004, WP-10, WP-7 · **Уровень:** L3 · **Тип:** soak
**Среда:** OS-W11-24H2, NET-BASE; пул из 5 фикстурных профилей; ротация каждые 15 мин.
**Оракул (PASS, если все условия):**
- 96 ротаций, 0 необъяснимых провалов; выборка утечек при каждой ротации — 0 пакетов мимо; рост RSS/handles ≤ 10% за сутки; журнал полон (каждая ротация с correlation id).
