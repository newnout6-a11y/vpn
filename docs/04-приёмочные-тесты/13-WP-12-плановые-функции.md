# WP-12. Плановые функции (mihomo, AmneziaWG, процессный монитор, изоляция аккаунтов) — набор тестов

**Покрывает:** F-166…F-180 (roadmap-дрейф), AC-CONN-CORE-001…003, AC-CONN-AWG-001…003, AC-MON-PROC-001…005, AC-ISO-001…007.
**Принцип:** ни одна плановая функция не входит в production без лабораторных критериев ниже и не обходит WP-0…WP-3.

---

### AT-12-001: Контракт CoreAdapter — conformance-набор
**Трассировка:** AC-CONN-CORE-001…003, F-180, WP-12 · **Уровень:** L2 · **Тип:** contract
**Шаги:**
1. Прогнать conformance-набор (start/stop/health/config-compile/stats/capabilities) на sing-box (референс) и на mihomo spike.
**Оракул (PASS, если все условия):**
- Оба адаптера проходят идентичный набор; любое отклонение явно декларировано в capabilities и обработано вызывающей стороной.
- Контракт запрещает адаптеру мутировать системное состояние вне lifecycle-координатора (проверка снапшотом системы после каждого вызова).

### AT-12-002: Лабораторный гейт плановых функций
**Трассировка:** F-166, F-167, WP-12, WP-0 · **Уровень:** L0/L2 · **Тип:** contract
**Оракул (PASS, если все условия):**
- В production-сборке код плановых функций либо отсутствует, либо недостижим (флаг off, UI скрыт, IPC-каналы не зарегистрированы — проверка AT-00-001).
- Включение требует записи о прохождении лабораторных критериев; без неё активация отклонена.

### AT-12-003: AmneziaWG — handshake probe и параметры
**Трассировка:** AC-CONN-AWG-001…003, F-171…F-175, WP-12 · **Уровень:** L1/L3 · **Тип:** functional, negative
**Шаги:**
1. Парсинг параметров `Jc/Jmin/Jmax/S1/S2/H1..H4` — границы и невалидные значения (L1).
2. Handshake probe: сервер не отвечает на probe; отвечает с задержкой > таймаута; отвечает корректно (L3).
**Оракул (PASS, если все условия):**
- Переключение шлюза заблокировано при отсутствии ответа на probe; при таймауте — честный статус, не «подключено».
- Невалидные параметры отклонены до запуска с перечнем полей.

### AT-12-004: Mihomo spike — preflight rejection
**Трассировка:** AC-CONN-CORE-002, F-180, WP-12 · **Уровень:** L1 · **Тип:** contract, negative
**Оракул (PASS, если все условия):**
- Профили, использующие неподдержанные spike-возможности, отклоняются preflight с точным списком неподдержанного; «молчаливой деградации» конфига нет (diff входа и скомпилированного конфига явен).

### AT-12-005: Процессный монитор — политика удержания и разрешений
**Трассировка:** AC-MON-PROC-001…005, F-176, F-178, WP-12 · **Уровень:** L2 · **Тип:** security, functional
**Оракул (PASS, если все условия):**
- Собираются только заявленные атрибуты (путь процесса, счётчики); retention-политика соблюдена (записи старше TTL удалены); доступ к данным монитора требует заявленного разрешения; отказ записан.

### AT-12-006: Изоляция аккаунтов MVP — сетевая граница на бокс
**Трассировка:** AC-ISO-001…007, F-177, F-179, WP-12 · **Уровень:** L3 · **Тип:** security, dual-oracle
**Шаги:**
1. Три бокса → три разных egress-профиля; попытка бокса A достучаться до локальных сервисов бокса B; проверка DNS.
**Оракул (PASS, если все условия):**
- Каждый бокс имеет изолированный UserDataDir и собственную сетевую границу: egress IP различаются согласно назначению, DNS — удалённый (0 локальных запросов от PID бокса).
- Кросс-доступ между боксами заблокирован; закрытие бокса убирает его сетевые правила без остатка.

### AT-12-007: Плановая функция не меняет sing-box lifecycle без миграции
**Трассировка:** F-170, WP-12, WP-0 · **Уровень:** L2 · **Тип:** contract, regression
**Оракул (PASS, если все условия):**
- Включение любой плановой функции не модифицирует существующий lifecycle sing-box без записи миграции; регрессионный набор WP-2 зелёный при включённых флагах.

### AT-12-008: Жизненный цикл адаптеров `VPNTE-TUN` / `awg-tun`
**Трассировка:** AC-CONN-AWG-002, WP-12, WP-3 · **Уровень:** L3 · **Тип:** functional matrix
**Среда:** вся OS-матрица.
**Оракул (PASS, если все условия):**
- Создание/удаление обоих адаптеров подтверждено на каждой ОС; после uninstall осиротевших адаптеров нет (`Get-NetAdapter` + перезагрузка); конфликт имён с чужим адаптером обработан явно.
