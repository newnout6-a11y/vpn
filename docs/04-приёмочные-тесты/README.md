## Как читать тест

Каждый тест: `AT-<WP>-<NNN>` — трассировка (AC/REQ/F/WP), уровень, тип(ы), среда, предусловия, шаги, **оракул с измеримыми условиями PASS**, очистка. Вердикты: PASS / FAIL / NOT-CHECKED / INDETERMINATE — NOT-CHECKED не считается успехом (см. методологию §1).
