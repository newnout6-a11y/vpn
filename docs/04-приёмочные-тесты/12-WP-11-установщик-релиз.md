# WP-11. Установщик, целостность релиза и политика зависимостей — набор тестов

**Покрывает:** F-163…F-169, F-182…F-184, F-209 (и регрессия F-162); технические требования поставки.

---

### AT-11-001: Чистая установка по OS-матрице
**Трассировка:** F-163, WP-11 · **Уровень:** L3 · **Тип:** functional matrix
**Среда:** OS-W10-22H2, OS-W11-23H2, OS-W11-24H2 — чистые образы.
**Шаги:** установка → первый запуск → мастер → подключение по фикстурному профилю → удаление.
**Оракул (PASS, если все условия):**
- На каждой ОС: установка завершается без ручных вмешательств, адаптеры созданы, мастер завершаем, трафик идёт через туннель (egress-проверка), удаление не оставляет осиротевших адаптеров/задач/правил.

### AT-11-002: Обновление с активной защитой
**Трассировка:** F-164, WP-11 · **Уровень:** L3 · **Тип:** upgrade, chaos
**Шаги:**
1. Активный туннель + kill-switch; запустить установщик новой версии.
**Оракул (PASS, если все условия):**
- Установщик вызывает безопасный shutdown приложения с rollback сетевых изменений; `taskkill` по имени образа не используется (мониторинг командных строк процессов установки).
- После обновления защита восстановлена либо честно снята с уведомлением; сеть никогда не остаётся в «полузащищённом» состоянии (проверка фильтров).

### AT-11-003: Прерванная установка — откат
**Трассировка:** F-165, WP-11 · **Уровень:** L3 · **Тип:** chaos
**Шаги:**
1. Hard reset VM на 30%/70% копирования файлов; загрузиться.
**Оракул (PASS, если все условия):**
- Система загружается в предыдущую рабочую версию или чистое состояние «не установлено»; пользовательские данные (профили, история, настройки) целы; boot recovery при необходимости отрабатывает.

### AT-11-004: Проверка подписей и хэшей артефактов
**Трассировка:** F-166, F-182, WP-11 · **Уровень:** L0/L3 · **Тип:** security
**Шаги:**
1. Подменить 1 байт в бинарнике ядра внутри ресурсов; пересобрать/запустить.
**Оракул (PASS, если все условия):**
- Все бинарники имеют зафиксированные версии и SHA-256/подписи; подмена обнаружена до упаковки (build gate) и до запуска (runtime check); `checksums.txt` совпадает с артефактами релиза побайтово.

### AT-11-005: Удаление — сохранность пользовательских данных
**Трассировка:** F-167, WP-11 · **Уровень:** L3 · **Тип:** functional, negative
**Оракул (PASS, если все условия):**
- Uninstall удаляет только заявленные артефакты (сверка снапшота FS/реестра до/после по allow-list); userData сохраняется согласно политике; задача boot recovery удалена.

### AT-11-006: Инвентарь ресурсов (F-209)
**Трассировка:** F-209, WP-11 · **Уровень:** L0 · **Тип:** contract
**Оракул (PASS, если все условия):**
- Resource manifest перечисляет каждый упаковываемый бинарник с версией и хэшем; отсутствие бинарника заваливает сборку с понятной ошибкой (регрессия удалённых wintun-файлов); лишний файл вне манифеста — предупреждение/ошибка по политике.

### AT-11-007: `dist:win` smoke на чистой VM
**Трассировка:** F-168, WP-11 · **Уровень:** L3 · **Тип:** functional
**Оракул (PASS, если все условия):**
- Свежесобранный NSIS устанавливается, приложение проходит smoke-набор (запуск, мастер, импорт фикстуры, подключение, диагностика, удаление) ≤ 15 мин.

### AT-11-008: Воспроизводимость сборки sidecar/snapshot
**Трассировка:** F-169, F-183, WP-11 · **Уровень:** L0 · **Тип:** build integrity
**Шаги:** два независимых прогона `build:sidecar` и `generate-v8-snapshot` на чистых агентах.
**Оракул (PASS, если все условия):**
- Хэши артефактов идентичны, либо каждое отличие входит в задокументированный список недетерминизма; отсутствие обязательного шага — диагностируемая ошибка или явно промаркированный fallback.

### AT-11-009: Согласованность NSIS-хуков (регрессия F-162)
**Трассировка:** F-162, WP-11 · **Уровень:** L0 · **Тип:** contract
**Оракул (PASS, если все условия):**
- Каждый хук/комментарий `build/installer.nsh` соответствует фактическому поведению (автоматизированная сверка вызовов и комментариев); расхождение — ошибка CI.

### AT-11-010: Политика автообновлений
**Трассировка:** F-184, WP-11 · **Уровень:** L2 · **Тип:** contract
**Оракул (PASS, если все условия):**
- Auto-update отсутствует/отключён до решения владельца; канал обновлений и политика зафиксированы; любая сетевая проверка обновлений проходит ту же валидацию подписи, что и установка.
