# Импорт и экспорт конфигурации

> Источник: https://factory.8090.ai/project/992274e4-1c6b-4d44-8c22-e4c038e690c2/requirements/7d522719-0e27-435e-a598-643fa5c80b6e

## Обзор

Функция «Импорт и экспорт конфигурации» позволяет пользователю сохранить конфигурацию VPN Tunnel Enforcer в JSON-файл и восстановить выбранные разделы из такого файла. Пользователь может проверить найденные разделы и конфликты перед применением, затем выбрать замену или слияние данных.

Текущая реализация охватывает профили VPN, группы серверов, расписания, приложения split tunneling, DNS, правила доменной маршрутизации, темы, ротацию профилей, kill-switch и уведомления. Экспорт включает чувствительные данные профилей без маскировки. Импорт проверяет версию файла и типы верхнего уровня, но не проверяет вложенные данные по схеме.

## Терминология

* **Конфигурация**: совокупность разделов настроек приложения, доступных для сохранения и восстановления.
* **Файл конфигурации**: JSON-файл версии `2.0`, содержащий один или несколько разделов конфигурации.
* **Раздел конфигурации**: самостоятельная часть конфигурации, которую можно выбрать для импорта.
* **Проверка импорта**: чтение файла конфигурации, проверка его формата и определение доступных разделов и конфликтов.
* **Конфликт конфигурации**: ситуация, когда выбранный раздел содержит данные и в текущей, и во входящей конфигурации.
* **Замена**: режим импорта, при котором выбранный раздел получает входящие данные вместо текущих.
* **Слияние**: режим импорта, при котором массивы выбранного раздела объединяются по идентификатору, а входящие значения имеют приоритет при совпадении.
* **Активный DNS-профиль**: идентификатор DNS-профиля, выбранного для использования; `null` означает системное значение по умолчанию.

## Требования

### REQ-SET-CFG-001: Экспорт конфигурации

**История пользователя:** Как пользователь VPN Tunnel Enforcer, я хочу сохранить текущую конфигурацию в файл, чтобы перенести или восстановить настройки приложения.

**Критерии приёмки:**

* **AC-SET-CFG-001.1:** Когда пользователь запускает экспорт, система должна предложить выбрать путь для JSON-файла.
* **AC-SET-CFG-001.2:** Когда пользователь подтверждает путь экспорта, система должна записать в файл текущие данные всех поддерживаемых разделов конфигурации и версию файла `2.0`.
* **AC-SET-CFG-001.3:** Когда пользователь отменяет выбор пути экспорта, система не должна изменять конфигурацию и должна завершить операцию как отменённую.
* **AC-SET-CFG-001.4:** Если запись файла экспорта завершается ошибкой, система должна сообщить об ошибке и не считать экспорт успешным.
* **AC-SET-CFG-001.5:** Если в конфигурации есть профили VPN, система должна записать их `outbound` и `sourceUri` в файл экспорта без маскировки, как в текущей реализации.

### REQ-SET-CFG-002: Проверка и выбор импорта

**История пользователя:** Как пользователь VPN Tunnel Enforcer, я хочу проверить файл импорта и выбрать нужные разделы, чтобы не менять лишнюю конфигурацию.

**Критерии приёмки:**

* **AC-SET-CFG-002.1:** Когда пользователь выбирает файл импорта, система должна принять только JSON-объект с версией `2.0` и минимум одним распознанным разделом.
* **AC-SET-CFG-002.2:** Когда файл импорта содержит распознанные разделы, система должна показать пользователю список доступных разделов для выбора.
* **AC-SET-CFG-002.3:** Когда файл импорта содержит массивный раздел с недопустимым верхнеуровневым типом, система должна отклонить файл и сообщить об ошибке формата.
* **AC-SET-CFG-002.4:** Когда файл импорта содержит объектный раздел с недопустимым верхнеуровневым типом, система должна отклонить файл и сообщить об ошибке формата.
* **AC-SET-CFG-002.5:** Когда текущая и входящая конфигурации содержат данные одного выбранного раздела, система должна обозначить этот раздел как конфликтующий.
* **AC-SET-CFG-002.6:** Если файл нельзя прочитать или разобрать как JSON, система должна отклонить импорт и показать ошибку.

### REQ-SET-CFG-003: Применение выбранной конфигурации

**История пользователя:** Как пользователь VPN Tunnel Enforcer, я хочу применить выбранные разделы с заменой или слиянием, чтобы управлять результатом восстановления конфигурации.

**Критерии приёмки:**

* **AC-SET-CFG-003.1:** Когда пользователь подтверждает импорт с режимом замены, система должна заменить данные каждого выбранного раздела входящими данными.
* **AC-SET-CFG-003.2:** Когда пользователь подтверждает импорт с режимом слияния, система должна объединить массивы выбранного раздела по идентификатору с приоритетом входящих элементов.
* **AC-SET-CFG-003.3:** Когда пользователь применяет раздел `dns`, система должна восстановить активный DNS-профиль только если его идентификатор присутствует среди записанных профилей.
* **AC-SET-CFG-003.4:** Когда пользователь не выбрал ни одного раздела, система не должна применять импорт и должна сообщить, что выбранные разделы отсутствуют.
* **AC-SET-CFG-003.5:** Если запись выбранного раздела завершается ошибкой, система должна попытаться восстановить состояние раздела до импорта и сообщить об ошибке применения.
* **AC-SET-CFG-003.6:** После успешного применения разделов расписаний, ротации или kill-switch система должна попытаться обновить соответствующее активное состояние приложения.

## Открытые вопросы

* Требуется решение, нужно ли защищать файл экспорта паролем и каким образом обрабатывать чувствительные данные профилей.
* Требуется решение, что делать при частично неверном файле импорта: отклонять весь файл, пропускать неверные элементы или применять только корректные разделы.
