# Автозапуск

> Источник: https://factory.8090.ai/project/992274e4-1c6b-4d44-8c22-e4c038e690c2/requirements/ba8cfe72-4cbe-4efe-9326-fc4a8bd05dcd

## Обзор

Функция «Автозапуск» позволяет приложению запускаться вместе с Windows и сохранять выбранное поведение при старте. Пользователь может включить или выключить запуск приложения при входе в Windows, выбрать автоматическое подключение VPN при запуске и указать запуск свёрнутым в область уведомлений.

Функция также обеспечивает подготовку восстановления сетевого состояния после аварийного завершения приложения. Восстановление сети после сбоя описано в отдельной фиче «Восстановление сети после сбоя» и не входит в область требований этой фичи.

## Терминология

* **Автозапуск приложения**: запуск VPN Tunnel Enforcer при входе пользователя в Windows.
* **Автоподключение VPN**: автоматическое начало VPN-защиты после запуска приложения.
* **Запуск свёрнутым в область уведомлений**: запуск приложения без показа основного окна, с доступностью через значок приложения в области уведомлений.
* **Область уведомлений**: системная область Windows, в которой приложение может оставаться доступным после запуска без основного окна.
* **Сохранённые настройки автозапуска**: значения параметров автозапуска, которые приложение использует после перезапуска.

## Требования

### REQ-SET-AUTO-001: Запуск приложения при входе в Windows

**История пользователя:** Как пользователь VPN Tunnel Enforcer, я хочу управлять запуском приложения при входе в Windows, чтобы VPN-защита была доступна без ручного запуска приложения.

**Критерии приёмки:**

* **AC-SET-AUTO-001.1:** При первом использовании функции значение автозапуска приложения должно быть выключено.
* **AC-SET-AUTO-001.2:** Когда пользователь включает автозапуск приложения, система должна сохранить включённое значение для следующих запусков.
* **AC-SET-AUTO-001.3:** Когда пользователь выключает автозапуск приложения, система должна сохранить выключенное значение для следующих запусков.
* **AC-SET-AUTO-001.4:** При входе пользователя в Windows, если автозапуск приложения включён, приложение должно запуститься.

### REQ-SET-AUTO-002: Поведение VPN при запуске приложения

**История пользователя:** Как пользователь VPN Tunnel Enforcer, я хочу управлять автоматическим подключением VPN при запуске приложения, чтобы защита начиналась без отдельного действия после старта.

**Критерии приёмки:**

* **AC-SET-AUTO-002.1:** Когда пользователь включает автоподключение VPN, система должна сохранить выбранное значение для следующих запусков.
* **AC-SET-AUTO-002.2:** При запуске приложения, если автоподключение VPN включено и необходимые исходные данные доступны, система должна начать VPN-защиту.
* **AC-SET-AUTO-002.3:** Если автоподключение VPN не может начаться, система должна оставить приложение запущенным и сообщить о состоянии, не выдавая неуспешный запуск за активную VPN-защиту.

### REQ-SET-AUTO-003: Запуск свёрнутым в область уведомлений

**История пользователя:** Как пользователь VPN Tunnel Enforcer, я хочу запускать приложение свёрнутым в область уведомлений, чтобы автоматический запуск не открывал основное окно без необходимости.

**Критерии приёмки:**

* **AC-SET-AUTO-003.1:** При первом использовании функции запуск свёрнутым в область уведомлений должен быть включён.
* **AC-SET-AUTO-003.2:** Когда запуск свёрнутым в область уведомлений включён, автоматический запуск приложения не должен показывать основное окно как начальный пользовательский интерфейс.
* **AC-SET-AUTO-003.3:** Когда запуск свёрнутым в область уведомлений выключен, автоматический запуск приложения должен оставлять основное окно доступным пользователю.
* **AC-SET-AUTO-003.4:** При запуске свёрнутым в область уведомлений пользователь должен иметь доступ к управлению приложением через область уведомлений.

## Границы функции

* Подготовка механизма восстановления сетевого состояния после сбоя относится к функции «Восстановление сети после сбоя».
* Детали реализации планировщика Windows, повышенных прав и подавления ошибок относятся к техническому описанию и не являются пользовательскими критериями этой фичи.
