# Мастер первого запуска

> Источник: https://factory.8090.ai/project/992274e4-1c6b-4d44-8c22-e4c038e690c2/blueprints/e34476ad-03d0-4700-9178-69caa0e6dd64

## Feature Summary

Мастер первого запуска реализует требования @Мастер первого запуска и отображается в клиентском контейнере Electron поверх приложения, пока `firstRunComplete` имеет значение `false`. Он проводит пользователя через выбор языка и темы, обнаружение прокси Happ, режима маршрутизации и уровня kill-switch, затем сохраняет выбранные параметры и завершение первого запуска.

## Component Blueprint Composition

* `AppSettings` и `normalizeSettings` из реализации настроек задают сохранённые значения `firstRunComplete`, `connectionMode`, `routingMode` и `firewallKillSwitch`. Нормализация проверяет `firstRunComplete` как булево значение и задаёт ему значение по умолчанию `false`.
* `App` показывает #FirstRunWizard, когда `settings.firstRunComplete` выключен. Он передаёт один и тот же обработчик для завершения и пропуска, сохраняет `firstRunComplete: true` через сохранение настроек, а при ошибке обновляет локальное состояние, чтобы закрыть мастер.
* `useAppStore` из `src/renderer/store.ts` хранит локальное состояние настроек и прокси, которое читает и обновляет #FirstRunWizard.

## Feature-Specific Components

```component
name: FirstRunWizard
container: Electron Renderer
responsibilities:
	- Показывает полноэкранный последовательный поток шагов выбора языка, темы, обнаружения Happ, режима работы и уровня kill-switch.
	- Запускает `detectHapp` при входе на шаг обнаружения и показывает состояние поиска, найденный прокси или возможность повторить попытку.
	- Вызывает `killSwitchSetLevel`, `themeSetActive`, `i18nSetLocale` и `saveSettings` при завершении; не вызывает завершение при ошибке обязательной операции.
	- Передаёт обработчику родителя пропуск мастера через `onSkip`.
```

#FirstRunWizard использует `useAppStore` для локального состояния и `App` для сохранения флага завершения. При штатном завершении компонент сначала применяет обязательный уровень kill-switch, затем тему и язык, после чего сохраняет `firstRunComplete`, `connectionMode` и `routingMode`.

`App` владеет видимостью мастера и обработкой пропуска. В текущем коде `onSkip` и `onComplete` направлены в `handleWizardComplete`, поэтому пропуск сохраняет `firstRunComplete` в родительском App.tsx, хотя сам FirstRunWizard в `handleSkip` только меняет язык и вызывает callback.

## System Contracts

### Key Contracts

* `firstRunComplete` по умолчанию равен `false`; при выключенном значении #AppShell показывает #FirstRunWizard.
* Успешное завершение мастера сохраняет `firstRunComplete: true`; после успешного callback мастер перестаёт отображаться в текущем сеансе и не должен отображаться после следующего запуска.
* Ошибка `killSwitchSetLevel`, `themeSetActive`, `i18nSetLocale` или сохранения завершения оставляет первый запуск незавершённым внутри #FirstRunWizard и показывает сообщение ошибки. Обработчик родителя при ошибке сохранения имеет fallback, который локально устанавливает `firstRunComplete: true`.
* Для пропуска в App.tsx используется тот же callback, что и для завершения. Проверка F-151 по строкам `FirstRunWizard.tsx:191-197` и `App.tsx:641-648, 680-682` подтверждает, что родительский `handleWizardComplete` сохраняет `firstRunComplete: true` через `saveSettings`, а при ошибке также устанавливает флаг локально. Следовательно, в проверенной реализации пропуск не вызывает повторное отображение мастера в текущем кодовом пути. Запись F-151 в журнале указывает на зависимость от родителя и не является подтверждением отсутствия сохранения в App.tsx.

### Integration Contracts

* API приложения возвращает результат обнаружения прокси или отсутствие результата; компонент показывает найденные `host`, `port` и `type`, если результат есть.
* API приложения принимает выбранный уровень `off`, `standard` или `strict`; ошибка блокирует завершение.
* API приложения применяет выбранную тему; ошибка блокирует сохранение завершения.
* API приложения применяет выбранный язык; ошибка блокирует сохранение завершения.
* Сохранение настроек получает `firstRunComplete: true`, `firewallKillSwitch`, `connectionMode` и `routingMode` при завершении мастера. При пропуске родитель передаёт ему только `firstRunComplete: true`.

## Architecture Decision Records

### ADR-001: Показывать мастер через состояние родительского приложения

**Context:** Видимость мастера должна зависеть от сохранённого признака завершения первого запуска, а завершение и пропуск должны иметь единый результат для родительского приложения.

**Decision:** App.tsx показывает #FirstRunWizard при `!settings.firstRunComplete` и передаёт `handleWizardComplete` одновременно в `onComplete` и `onSkip`. Сам компонент отвечает за шаги и операции настройки, а родитель отвечает за сохранение флага завершения.

**Consequences:** Пропуск корректно сохраняет флаг в текущем кодовом пути, но компонент зависит от callback родителя. Изменение родительского callback может снова повлиять на гарантию F-151.
