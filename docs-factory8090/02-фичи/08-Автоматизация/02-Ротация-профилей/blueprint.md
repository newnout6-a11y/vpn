# Ротация профилей

> Источник: https://factory.8090.ai/project/992274e4-1c6b-4d44-8c22-e4c038e690c2/blueprints/b7146663-c1ec-45aa-91c6-7c4ec686a964

## Feature Summary

Фича автоматически выбирает следующий доступный VPN-профиль через заданный интервал и при работающем туннеле выполняет защищённое переподключение. Она реализует требования @Ротация профилей: настройку набора профилей, порядка выбора, таймера, немедленной смены и уведомлений о результате.

## Component Blueprint Composition

Фича использует `serverPicker` и `smartOfflinePing` для получения профилей и проверки доступности. При работающем туннеле `#ProfileRotationService` передаёт новый `ServerProfile` в `#TunController`, который выполняет защищённое переподключение и сохраняет включённые защитные настройки.

`#RotationSettings` вызывает IPC-каналы `rotation:get-config`, `rotation:set-config` и `rotation:rotate-now`. Main process возвращает `RotationConfig`, а событие `server-active-changed` обновляет отображение активного профиля в renderer.

## Feature-Specific Components

### Main process

```component
name: ProfileRotationService
container: Electron Main Process
responsibilities:
	- Хранит и нормализует `RotationConfig` в electron-store.
	- Планирует одну следующую попытку ротации через таймер.
	- Выбирает следующий доступный `ServerProfile` в последовательном или случайном порядке.
	- Пропускает профили с подтверждённой недоступностью.
	- Вызывает #TunController для защищённого переподключения работающего туннеля.
	- Публикует уведомления о смене и ошибке ротации.
```

### Renderer

```component
name: RotationSettings
container: Electron Renderer Process
responsibilities:
	- Загружает и показывает `RotationConfig` и список `ServerProfile`.
	- Позволяет включать ротацию, задавать интервал, порядок и набор профилей.
	- Показывает текущий профиль и время до следующей попытки.
	- Запускает немедленную ротацию через IPC.
	- Показывает ошибки загрузки, сохранения и ротации.
```

## System Contracts

### Key Contracts

* `RotationConfig.intervalMinutes` ограничивается диапазоном от 5 до 1440 минут.
* Пустой набор профилей не запускает таймер и не выполняет смену.
* Повторный запуск ротации блокируется локальным состоянием `rotationInProgress`.
* Ошибка переподключения не отключает следующую запланированную попытку.
* Общая блокировка жизненного цикла между ротацией, расписанием, AutoPilot, ручными действиями и adaptive retry в текущем коде не подтверждена.

### Integration Contracts

* `rotation:get-config` возвращает текущий `RotationConfig`.
* `rotation:set-config` принимает частичное изменение, валидирует поля и возвращает нормализованную конфигурацию.
* `rotation:rotate-now` выполняет одну попытку и возвращает результат с признаком успеха и идентификатором профиля.
* `server-active-changed` передаёт renderer идентификатор и название выбранного профиля.
* Уведомления используют категории `profileRotation` для смены и `connectionError` для ошибки переподключения.

## Architecture Decision Records

### ADR-001: Таймер с одной следующей попыткой

**Context:** Ротация должна работать через настраиваемый интервал и не создавать параллельные таймеры при изменении настроек.

**Decision:** Хранить время следующей попытки в `RotationConfig` и заменять предыдущий таймер при изменении конфигурации.

**Consequences:** Состояние следующего запуска сохраняется. После ошибки функция остаётся включённой и планирует следующую попытку. Общая отмена с другими владельцами жизненного цикла пока не реализована.

### ADR-002: Защищённое переподключение работающего туннеля

**Context:** Простая смена выбранного профиля не меняет уже запущенный туннель.

**Decision:** Передавать новый профиль в защищённый путь переподключения `#TunController`, сохраняя включённые параметры защиты.

**Consequences:** Смена профиля соответствует фактическому переподключению и возвращает ошибку при неудаче. F-124 остаётся открытым: код выбирает новый профиль до подтверждения успешного переподключения.
