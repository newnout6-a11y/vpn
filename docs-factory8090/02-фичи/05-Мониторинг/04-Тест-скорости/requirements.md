# Тест скорости

> Источник: https://factory.8090.ai/project/992274e4-1c6b-4d44-8c22-e4c038e690c2/requirements/43f6eb46-58f1-4eb7-b42d-386e415b25fb

## Обзор

Функция «Тест скорости» позволяет пользователю измерить производительность активного VPN-соединения. Она показывает задержку, скорость загрузки и скорость отправки, сообщает ход измерения и сохраняет результаты для последующего сравнения.

Измерение выполняется только при активном VPN-соединении. Для разных этапов используются внешние HTTPS-сервисы: задержка измеряется по первому доступному адресу из набора Cloudflare, Google, Google Connectivity Check, Firefox Detect Portal и `1.1.1.1`; загрузка проверяется через Cloudflare, OVH или Tele2 с переходом к следующему серверу при ошибке; отправка выполняется через Cloudflare. Точный выбор сервиса загрузки является частью результата.

## Терминология

* **Тест скорости**: последовательное измерение задержки, скорости загрузки и скорости отправки через активное VPN-соединение.
* **Задержка**: время кругового запроса до выбранного сервиса проверки задержки.
* **Скорость загрузки**: измеренная скорость получения данных от сервиса загрузки.
* **Скорость отправки**: измеренная скорость передачи данных в сервис отправки.
* **Сервис измерения**: внешний HTTPS-адрес, используемый для одного из этапов теста.
* **Результат теста**: сохранённая запись с идентификатором, временем, тремя измеренными показателями, именем сервиса загрузки и именем использованного VPN-профиля.
* **История тестов**: локальный список сохранённых результатов теста, содержащий не более 50 последних записей.
* **Активное VPN-соединение**: состояние, при котором приложение сообщает, что VPN-туннель запущен.

## Требования

### REQ-MON-SPD-001: Запуск теста через VPN

**История пользователя:** Как пользователь, я хочу запустить тест скорости при активном VPN-соединении, чтобы оценить фактическую производительность защищённого подключения.

**Критерии приёмки:**

* **AC-MON-SPD-001.1:** Когда пользователь запускает тест при активном VPN-соединении, система должна последовательно измерить задержку, скорость загрузки и скорость отправки.
* **AC-MON-SPD-001.2:** Пока VPN-соединение не активно, система должна запретить запуск теста и сообщить пользователю, что сначала нужно подключить VPN.
* **AC-MON-SPD-001.3:** Когда другой тест уже выполняется, система должна отклонить повторный запуск и сообщить, что тест уже выполняется.
* **AC-MON-SPD-001.4:** Если измерение не может завершиться, система должна сообщить об ошибке и не сохранять неподтверждённый результат.

### REQ-MON-SPD-002: Измерение и отображение показателей

**История пользователя:** Как пользователь, я хочу видеть результаты измерения по отдельным показателям, чтобы понимать качество соединения.

**Критерии приёмки:**

* **AC-MON-SPD-002.1:** Во время теста система должна сообщать текущую фазу и процент выполнения для задержки, загрузки и отправки.
* **AC-MON-SPD-002.2:** После успешного теста система должна показать задержку в миллисекундах.
* **AC-MON-SPD-002.3:** После успешного теста система должна показать скорость загрузки в мегабитах в секунду.
* **AC-MON-SPD-002.4:** После успешного теста система должна показать скорость отправки в мегабитах в секунду.
* **AC-MON-SPD-002.5:** После успешного теста система должна показать имя сервиса загрузки и использованный VPN-профиль.

### REQ-MON-SPD-003: Выбор сервисов измерения

**История пользователя:** Как пользователь, я хочу получить результат при временной недоступности одного внешнего сервиса, чтобы единичный сбой не блокировал измерение.

**Критерии приёмки:**

* **AC-MON-SPD-003.1:** При измерении задержки система должна проверить адреса сервисов по заданному порядку и использовать первый адрес, который даёт не менее трёх успешных ответов.
* **AC-MON-SPD-003.2:** При измерении загрузки система должна проверить сервисы Cloudflare, OVH и Tele2 по заданному порядку и перейти к следующему сервису, если текущий недоступен.
* **AC-MON-SPD-003.3:** Если ни один сервис загрузки недоступен, система должна завершить тест с ошибкой вместо результата без скорости загрузки.
* **AC-MON-SPD-003.4:** Если недостаточно успешных ответов всех сервисов задержки, система должна завершить тест с ошибкой вместо неподтверждённой задержки.

### REQ-MON-SPD-004: История результатов

**История пользователя:** Как пользователь, я хочу просматривать прошлые результаты теста, чтобы сравнивать производительность VPN-соединения во времени.

**Критерии приёмки:**

* **AC-MON-SPD-004.1:** После успешного теста система должна сохранить его результат локально на устройстве.
* **AC-MON-SPD-004.2:** При открытии страницы теста система должна показать сохранённые результаты с временем, задержкой, скоростью загрузки, скоростью отправки, сервисом загрузки и VPN-профилем.
* **AC-MON-SPD-004.3:** При отсутствии сохранённых результатов система должна показать состояние пустой истории.
* **AC-MON-SPD-004.4:** После сохранения более 50 результатов система должна оставить в истории только 50 последних результатов.

### REQ-MON-SPD-005: Проверка использования VPN

**История пользователя:** Как пользователь, я хочу знать, что измерение относится к VPN-соединению, чтобы не принять прямое соединение за результат VPN.

**Критерии приёмки:**

* **AC-MON-SPD-005.1:** Перед сохранением результата система должна попытаться сравнить внешний IP теста с текущим IP, полученным мониторингом.
* **AC-MON-SPD-005.2:** Если проверка внешнего IP выявляет несовпадение, система не должна считать результат подтверждённым использованием активного VPN-туннеля.
* **AC-MON-SPD-005.3:** Если проверка внешнего IP не может выполниться, система должна отдельно обработать эту ошибку и не выдавать пользователю неподтверждённое утверждение о корректности VPN-маршрута.
