# Локализация интерфейса

## Capability Summary

Возможность предоставляет renderer локализацию через i18next и react-i18next с ресурсами `ru.json` и `en.json`. Начальный язык выбирается по `navigator.language`, затем может быть заменён сохранённой локалью из main. Полнота перевода ограничена: часть русских строк остаётся прямо в компонентах renderer, F-020.

## Core Components

### Инициализация i18n

```component
name: RendererI18n
container: Renderer
responsibilities:
	- Регистрирует ресурсы en и ru через i18next и initReactI18next.
	- Выбирает начальную локаль ru для navigator.language, начинающегося с ru, иначе en.
	- Использует en как fallback и отключает escaping для React-интерполяции.
	- После старта получает сохранённую локаль через ElectronAPI и меняет язык.
```

### Ресурсы переводов

```component
name: LocaleResources
container: Renderer
responsibilities:
	- Содержит словари интерфейса ru.json и en.json.
	- Предоставляет ключи translation для компонентов renderer.
```

#RendererI18n загружает #LocaleResources при старте и использует preload API для получения persisted locale. Компоненты, которые обращаются к ключам переводов, зависят от полноты обоих словарей.

## System Contracts

### Key Contracts

* Поддерживаемые локали должны иметь ресурс в обоих словарях или явно использовать fallback en.
* Изменение локали должно быть доступно renderer через i18n API и main через IPC.
* Русские строки, встроенные в компоненты, нарушают полноту локализации и должны считаться drift, F-020.
* Текст интерфейса не должен требовать изменения runtime-логики при добавлении перевода.

### Integration Contracts

* #RendererI18n использует `i18nGetLocale`, а смена языка получает событие через preload-контракт.
* Компоненты renderer используют i18next/react-i18next translation resources.
* Main хранит и возвращает выбранную локаль через IPC, renderer применяет её после инициализации.

## Architecture Decision Records

### ADR-001: i18next как слой локализации

**Context:** Интерфейс содержит много текстов и должен поддерживать русскую и английскую локали.

**Decision:** Использовать i18next с react-i18next и JSON-словарями.

**Consequences:** Переводы отделены от компонентов, но требуется контроль отсутствующих ключей и строк, оставшихся в коде.

### ADR-002: Определение языка в два этапа

**Context:** Renderer может определить системный язык до загрузки persisted-настроек из main.

**Decision:** Сначала использовать navigator.language, затем заменить его сохранённой локалью.

**Consequences:** При старте возможен короткий показ первичного языка до ответа main.
