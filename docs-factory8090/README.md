# Исследование VPN Tunnel Enforcer (Software Factory 8090)

Эта папка содержит результаты reverse engineering и аудита репозитория, выполненных в Software Factory (https://factory.8090.ai). Код репозитория при этом не изменялся.

Дата выгрузки: 2026-09-26, обновлена после проверки ветки. Источник: проект Software Factory «Project one».

## Как читать

- **Требования** (`requirements.md`) описывают, что делает продукт и зачем.
- **Блюпринты** (`blueprint.md`) описывают, как это устроено технически.
- **Журнал аудита** содержит находки F-001..F-185: баги, расхождения, устаревшие решения. При повторной проверке F-151 и F-162 опровергнуты, F-154 частично устарела.
- **Открытые вопросы** собраны из комментариев к документам. На них нужен ответ владельца продукта.

Документы описывают код на момент исследования. После новых коммитов в `main` часть фактов может устареть.

## Структура

- `00-журнал-аудита.md`: журнал находок и таблица проверок.
- `01-обзор/`: 6 обзорных документов (бизнес-проблема, текущее состояние, описание продукта, персоны, метрики, технические требования).
- `02-фичи/`: 44 фичи. Каждая папка содержит `requirements.md` и `blueprint.md`. Дочерние фичи лежат во вложенных папках. Суффикс `план` означает фичу, которой ещё нет в коде.
  - `01-Подключение-VPN/`
  - `02-Защита-от-утечек/`
  - `03-Серверы-и-подписки/`
  - `04-Маршрутизация/`
  - `05-Мониторинг/`
  - `06-Диагностика/`
  - `07-Soft-режим/`
  - `08-Автоматизация/`
  - `09-Настройки/`
  - `10-Изоляция-аккаунтов-план/`
- `03-контейнеры/`: развёртываемые части системы и общая схема архитектуры.
- `04-компоненты/`: сквозные технические компоненты.
- `05-открытые-вопросы.md`: открытые вопросы по документам.
- `06-ТЗ-исправление-и-развитие.md`: единое ТЗ на исправление аудиторских находок, внедрение требований и плановых функций; открытые вопросы остаются отдельным реестром.
