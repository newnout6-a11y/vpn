# Исследование и консолидированная документация VPN Tunnel Enforcer (Software Factory 8090)

Эта папка содержит результаты reverse engineering, глубокого технического аудита репозитория, утверждённые решения владельца продукта и план исправлений/развития (рабочие пакеты WP-0..WP-12).

- **Дата актуализации:** 2026-09-28 (ревизия журнала аудита)
- **Покрытие аудита:** 100% (все 210 находок F-001..F-210 учтены; опровергнутые помечены в журнале, раздел «Ревизия 2026-09-28»).
- **Покрытие решений владельца:** 100% (все 13 блоков решений и 128 вопросов реестра зафиксированы).
- **Покрытие рабочих пакетов:** 100% (WP-0..WP-12 детально распределены по смысловым томам).

## Состав этой папки

- `00-журнал-аудита.md`: журнал находок F-001..F-210, таблицы проверок и раздел «Ревизия 2026-09-28» (опровергнутые/уточнённые/новые находки F-202..F-210).
- `01-обзор/`: 6 обзорных документов (бизнес-проблема, текущее состояние, описание продукта, персоны, метрики, технические требования).
- `02-фичи/`: 44 фичи в 10 каталогах (`requirements.md` + `blueprint.md` на каждое направление, 88 документов).
- `03-контейнеры/`: архитектурные схемы и спецификации контейнеров системы.
- `04-компоненты/`: сквозные технические спецификации компонентов.
- `05-открытые-вопросы.md`: полный реестр 128 вопросов с зафиксированными статусами.
- `06-ТЗ-исправление-и-развитие.md`: единое ТЗ с утверждёнными решениями владельца по блокам 1–8 и 10–13, блоком 9 (подпись отложена), описанием рабочих пакетов WP-0..WP-12.
- `../vpn-tunnel-enforcer/docs/`: дорожные карты censorship resilience (фазы 1–8), adaptive bypass, multi-account isolation, traffic observability RFC — инженерные документы приложения (планы; статусы см. в заголовках документов).
