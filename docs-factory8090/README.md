- **Покрытие рабочих пакетов:** 100% (WP-0..WP-12 детально распределены по смысловым томам).

- `00-журнал-аудита.md`: журнал находок F-001..F-210, таблицы проверок и раздел «Ревизия 2026-09-28» (опровергнутые/уточнённые/новые находки F-202..F-210).

- `02-фичи/`: 44 фичи в 10 каталогах, по одному `requirements.md` (REQ и критерии приёмки AC; из них генерируется `docs/04-приёмочные-тесты/traceability/ac-inventory.csv`). Описания реализации (`blueprint.md`, 44 файла) удалены 2026-10-13 как устаревшие, сохранены в истории git.
- `05-открытые-вопросы.md`: полный реестр 128 вопросов с зафиксированными статусами.
- `06-ТЗ-исправление-и-развитие.md`: единое ТЗ с утверждёнными решениями владельца по блокам 1–8 и 10–13, блоком 9 (подпись отложена), описанием рабочих пакетов WP-0..WP-12.
