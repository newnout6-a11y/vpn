# Technical Requirements

> Источник: https://factory.8090.ai/project/992274e4-1c6b-4d44-8c22-e4c038e690c2/requirements/a6e012b4-80d5-44d4-9642-4f645104925c

Приложение работает только на Windows и требует прав администратора, потому что меняет правила Windows Firewall, маршруты, DNS и состояние сетевых адаптеров. Установщик ставит приложение для всех пользователей машины. Приложение должно корректно работать на Windows 10 и Windows 11. Поддержка Windows 10 завершена Microsoft 14 октября 2025 года, поэтому решение о дальнейшей поддержке нужно принять явно.

Системный туннель строится на sing-box и драйвере Wintun. Для профилей REALITY используется Xray. Все внешние бинарники поставляются вместе с приложением. Туннель намеренно использует только IPv4, а IPv6 блокируется, чтобы исключить утечки. Основной туннель не должен зависеть от доступности внешних сервисов: правила маршрутизации имеют локальные копии, а сбой обновления подписки или rule-set не должен ломать подключение.

Любое изменение системной сети должно иметь откат и проверку результата. Приложение должно восстанавливать сеть после аварийного завершения, в том числе при загрузке Windows через задачу, которая работает от имени SYSTEM. Процессы, которые запустило приложение, не должны оставаться работать после выхода.

VPN-ключи и токены являются секретами. Они не должны попадать в журналы, диагностические архивы и сообщения об ошибках. Интерфейс не обращается к Windows API, файловой системе или командной оболочке напрямую: все действия идут через проверенный канал к основному процессу. Локальный API управления прокси доступен только с loopback-адреса и требует токен.

Документы проекта заявляют эти правила как инварианты. Аудит сентября 2026 года показал, что часть из них соблюдается не полностью (хранение ключей, проверка отправителя в IPC, откат при сбое записи манифеста). Подробности в журнале аудита кода в базе знаний.
