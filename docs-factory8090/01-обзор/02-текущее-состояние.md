# Current State

> Источник: https://factory.8090.ai/project/992274e4-1c6b-4d44-8c22-e4c038e690c2/requirements/3b05b961-00d4-41a7-99f6-b51de3aa6caa

VPN Tunnel Enforcer существует как рабочее Electron-приложение для Windows (на момент исследования, 2026-09: версия пакета 1.1.22, Electron 42; на 2026-10-13: версия 1.1.24, Electron 44.4.3). Оно запускает sing-box с драйвером Wintun, а для профилей REALITY использует Xray. Приложение поддерживает два способа подключения: через локальный прокси другого клиента и прямой VPN по импортированному ключу. Также есть Soft-режим, в котором приложение только настраивает прокси в системе и инструментах разработчика.

Реализованы kill-switch на базе Windows Firewall с тремя уровнями, блокировка физических адаптеров и IPv6, защита браузеров от WebRTC-утечек, восстановление сети при загрузке Windows, импорт ключей и подписок многих форматов, Smart RU маршрутизация, доменные правила, раздельное туннелирование приложений, мониторинг IP и трафика, тест скорости, проверка доступности сайтов, диагностика утечек, форензика трафика через pktmon и ETW, внешний локальный прокси, расписание, ротация профилей, AutoPilot и адаптивный обход блокировок. В репозитории около 120 файлов тестов.

Аудит кода в сентябре 2026 года записал 185 находок (F-001…F-185) в журнал аудита в базе знаний. При повторной проверке две находки опровергнуты (F-151, F-162), одна частично устарела (F-154). Главные группы проблем:

* Секреты. VPN-ключи хранятся и экспортируются открытым текстом, а IPC-граница не проверяет отправителя.
* Надёжность защиты. Есть сценарии, в которых после сбоя система остаётся в режиме блокировки или откатывается в Allow. Некоторые проверки утечек не могут дать положительный результат.
* Устаревшие решения. Поддержка Electron 42 заканчивалась в октябре 2026 года; миграция на Electron 44.4.3 выполнена 2026-09-30. WireGuard outbound удалён в sing-box 1.13; с 2026-10-13 код собирает его как `endpoint` (PR #36). Android Studio хранит прокси в другом файле. Frontend-стек отстаёт на одну мажорную версию.
* Поставка. Нет подписи кода, контрольных сумм бинарников и автообновления. При обновлении установщик принудительно завершает приложение и sing-box без штатного отката сетевой защиты. Это нужно проверить на устройстве.
* Документация. README и внутренние документы расходятся с кодом по версиям, поведению сохранения настроек и статусу планов.

Запланированы, но не реализованы: изоляция нескольких аккаунтов в отдельных браузерных профилях, альтернативное ядро mihomo через общий адаптер, протокол AmneziaWG и постоянный процессный монитор трафика.
