# Product Description

> Источник: https://factory.8090.ai/project/992274e4-1c6b-4d44-8c22-e4c038e690c2/requirements/459cacd5-1af3-4733-833b-1e0a4fb182f3

VPN Tunnel Enforcer — настольное приложение для Windows, которое гарантирует, что весь сетевой трафик компьютера идёт через VPN. Пользователь выбирает сервер и нажимает «Подключить». Приложение поднимает системный туннель, закрывает обходные пути и следит, чтобы защита оставалась включённой, пока пользователь её не выключит.

Продукт состоит из нескольких групп возможностей. **Подключение VPN** управляет туннелем, выбирает ядро, автоматически перезапускает его после сбоев и подбирает режим совместимости при блокировках. **Защита от утечек** блокирует трафик мимо туннеля через firewall, отключает физические адаптеры и IPv6, защищает браузеры и восстанавливает сеть после аварийного завершения. **Серверы и подписки** импортируют ключи и подписки, группируют серверы, проверяют их и позволяют открыть отдельный сервер как локальный прокси для других программ. **Маршрутизация** направляет российские сайты напрямую (Smart RU), применяет доменные правила, исключает приложения из туннеля и задаёт DNS.

**Мониторинг** показывает текущий IP, скорость и историю трафика, проверяет доступность сайтов и скорость соединения. **Диагностика** проверяет утечки и маршруты, собирает архив для поддержки, записывает трафик для анализа и даёт инструменты обслуживания. **Soft-режим** настраивает прокси в переменных окружения, Git, Gradle и Android Studio без системного туннеля. **Автоматизация** включает VPN по расписанию, меняет профили по ротации и реагирует на чужие туннели через AutoPilot. **Настройки** охватывают мастер первого запуска, импорт и экспорт конфигурации, уведомления, тему, язык и автозапуск.

Интерфейс доступен на русском и английском языках. Приложение работает с правами администратора, потому что меняет firewall, маршруты и сетевые адаптеры.
