# Сайт VPN Tunnel Enforcer

Статический многостраничный маркетинговый сайт: 8 страниц + 404. Без фреймворка и без сторонних запросов. Шрифты, иконки, GSAP и Lenis лежат локально в `public/`.

```bash
cd website
npm install
npm run dev     # сборка + сервер на http://localhost:4173 с пересборкой при правках
npm run build   # результат в dist/ (деплоится как есть, пути относительные)
npm run og      # пересобрать public/assets/og.png
npm run world   # пересобрать точки суши для глобуса (public/js/world-data.js)
node tools/lint-html.mjs   # баланс тегов и битые ссылки в dist/
```

Для `canonical`, `sitemap.xml` и абсолютного `og:image` задайте адрес при сборке: `SITE_URL=https://example.com npm run build`.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/layout.html`, `src/partials/` | общий каркас, шапка, подвал |
| `src/pages/*.html` | страницы; первая строка — JSON с `path`, `title`, `description`, `nav` |
| `public/css/site.css` | дизайн-система (токены, компоненты, адаптив) |
| `public/js/site.js` | поведение; каждый блок включается только при наличии своей разметки |
| `tools/` | микро-сборщик, dev-сервер, генераторы, проверки (Puppeteer — только для скриншотов) |

## Интерактивы

Туннель из арок в hero (canvas), симулятор обрыва туннеля (kill-switch), симулятор маршрутизации по порядку правил sing-box, глобус из точек Natural Earth, закреплённая при скролле история запуска туннеля, фильтры протоколов и FAQ с поиском.

## Источники идей

Референсы смотрели как ориентиры для приёмов, код и ассеты не копировали: Linear (подсветка карточек за курсором), Stripe и Railway (градиентные свечения), Vercel (сетка и моно-метки), Mullvad и Proton (открытое описание ограничений), Tailscale (схемы сети), Resend (типографика).

## Ассеты и лицензии

Bitter, Golos Text, Fira Mono (SIL OFL, файлы woff2 из пакетов `@fontsource-variable` и `@fontsource`); иконки Lucide (ISC) и логотип GitHub из Simple Icons (CC0); GSAP (стандартная лицензия GreenSock, бесплатна для сайтов без перепродажи), Lenis (MIT); карта суши — Natural Earth (public domain) через `world-atlas`. Логотип нарисован с нуля.
