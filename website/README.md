# Сайт VPN Tunnel Enforcer

Статический многостраничный маркетинговый сайт: 8 страниц + 404. Без фреймворка и без сторонних запросов. Шрифты, иконки, GSAP и Lenis лежат локально в `public/`.

```bash
cd website
npm install
npm run dev     # сборка + сервер на http://127.0.0.1:4173 (только loopback) с пересборкой при правках
npm run build   # результат в dist/ (деплоится как есть, пути относительные)
npm run og      # пересобрать public/assets/og.png
npm run world   # пересобрать точки суши для глобуса (public/js/world-data.js)
node tools/lint-html.mjs   # баланс тегов и битые ссылки в dist/
node tools/check.mjs       # поведение в Chrome: рубильник, пролёт, аварийный режим, якорь, все страницы на четырёх ширинах
node tools/shot.mjs /features/ 390 844 fullpage   # снимок в ../.tmp/shots; в Git Bash — с MSYS_NO_PATHCONV=1, иначе «/» станет путём Windows
```

Для `canonical`, `sitemap.xml` и абсолютного `og:image` задайте адрес при сборке: `SITE_URL=https://example.com npm run build`. Если сайт лежит в подпапке, `SITE_URL` обязателен: страница 404 отдаётся с любого адреса и не может ссылаться на ресурсы относительными путями.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/layout.html`, `src/partials/` | общий каркас, шапка, подвал |
| `src/pages/*.html` | страницы; первая строка — JSON с `path`, `title`, `description`, `nav` |
| `public/css/site.css` | дизайн-система (токены, компоненты, адаптив) |
| `public/js/site.js` | поведение; каждый блок включается только при наличии своей разметки |
| `tools/` | микро-сборщик, dev-сервер, генераторы, проверки (Puppeteer — только для скриншотов) |

## Интерактивы

- **Рубильник в hero.** Кнопка (или Shift+K) обрывает демо-туннель: hero уходит в чернила, заголовок перебивается, пакеты в туннеле упираются в стену, внизу появляется плашка fail-closed со счётчиком, через несколько секунд идёт авторестарт. Пульт показывает режим «Туннель» с kill switch `standard`, его журнал повторяет порядок старта клиента. Это демонстрация, а не реальное соединение — так и подписано на пульте.
- **Пролёт сквозь туннель.** На десктопе hero закреплён на один экран скролла: арки разгоняются, строки заголовка разъезжаются, тёмная арка вырастает из точки схода и переводит в тёмную секцию.
- **Живая типографика.** Unbounded — вариативный шрифт: жирность букв заголовка и слова в подвале тянется за курсором.
- Бегущие строки, скорость и наклон которых зависят от скорости скролла; карточки-стопка; цифры-одометры; арочный переход между страницами; курсор-кольцо, магнитные кнопки.
- Симулятор обрыва туннеля (kill switch выключен и включён), симулятор маршрутизации, глобус из точек Natural Earth, закреплённая история запуска «Туннеля», фильтры протоколов и FAQ с поиском.
- Порядок правил симулятора маршрутизации сверен с генератором клиента: `vpn-tunnel-enforcer/crates/engine/src/singbox_config/route.rs` (свои входы, процессы, QUIC, IPv6, перехват DNS, частные сети, STUN) и `crates/engine/src/routing/plan.rs` (блок, закрепления Smart RU, gov-ru, правила пользователя, geoip-ru). Переключатели: режим «Прокси» / «Туннель», QUIC, Smart RU. Домены Smart RU в симуляторе — короткие выборки из `smart_ru.rs`.
- История запуска на «Как работает» повторяет старт «Туннеля» из `crates/tunnel` и `crates/winnet`: права, фильтры WFP до движка, сверка SHA-256, конфигурация через stdin, подъём TUN, сторожа.

При `prefers-reduced-motion` всё перечисленное отключается, а контент остаётся статичным и читаемым. Если `site.js` не загрузился или упал, через 3 секунды включается класс `js-fail` и контент показывается без анимаций.

## Источники идей

Референсы смотрели как ориентиры для приёмов, код и ассеты не копировали: Vercel (сетка и моно-метки), Mullvad и Proton (открытое описание ограничений), Tailscale (схемы сети), Resend (типографика). Свечения в духе Stripe и Railway и подсветка карточек за курсором в духе Linear убраны при проходе unslop (ниже).

## Ассеты и лицензии

Unbounded, Golos Text, Fira Mono (SIL OFL, файлы woff2 из пакетов `@fontsource-variable` и `@fontsource`); иконки Lucide (ISC) и логотип GitHub из Simple Icons (CC0); GSAP (стандартная лицензия GreenSock, бесплатна для сайтов без перепродажи), Lenis (MIT); карта суши — Natural Earth (public domain) через `world-atlas`. Логотип нарисован с нуля.

## Что нужно проверить владельцу

- Сайт описывает клиент 2.0.0 на Rust. Все факты (режимы «Прокси» и «Туннель», 11 видов ключей, версии движков, цифры тестов, что не проверено) взяты из `README.md`, `vpn-tunnel-enforcer/README.md`, `ВОПРОСЫ-ВЛАДЕЛЬЦУ.md`, `.tmp/rewrite/NOADMIN.md`, `.tmp/rewrite/spec/ru-2026-plan.md`, `API.md` крейтов и `resources/engines.toml` на 12.11.2026. Число «2751 тест», версии движков и статусы на «Дорожной карте» устареют, и их надо обновлять.
- Утверждения без источника убраны: «без аналитики и телеметрии», «0 SDK трекеров», сравнение с «типичным клиентом». Вопрос о телеметрии в FAQ заменён списком запросов, которые клиент делает сам. Если хотите вернуть обещание «без телеметрии», сначала запишите его в README клиента.
- Публичного релиза нет, поэтому страница «Сборка и релизы» (`/download/`) честно это сообщает, а кнопки на остальных страницах ведут на сборку из исходников, а не обещают загрузку. Когда релиз появится, замените блок статуса на прямые ссылки на установщик, переносной архив и `checksums.txt`.
- Подпись кода — открытый вопрос (`ВОПРОСЫ-ВЛАДЕЛЬЦУ.md`, пункт 1), на сайте сказано «не решено». Открытыми показаны и вопросы о службе-помощнике, IPv6 через VPN и mihomo в обычной сборке.
- Сайт позиционирует продукт как клиент с вашими ключами, а не как VPN-сервис с серверами и тарифами. Если у вас свои серверы или платные планы, нужны страница с ценами и правки текстов.

## Проход unslop (12.11.2026)

Режим polish: сайт сделан руками и со своим характером (бумага, чернила, один сигнальный оранжевый, Unbounded), поэтому раскладка, палитра, шрифты и все интерактивы сохранены, исправлены только найденные признаки. Скриншоты до и после — каждая страница на 1440 и 390 px (`tools/shot.mjs`, файлы в `../.tmp/shots/`).

Найдено и исправлено:

- **Цветные свечения.** Бегущий конический луч по рамке пульта и красная тень пульта при обрыве; свечение точки в шапке пульта; оранжевое пятно за курсором на карточках (CSS и обработчик в `site.js`); оранжевый ореол вокруг глобуса и свечение головы маршрута. Состояние пульта теперь несёт цвет рамки, точка и кольцо статуса.
- **Метки капсом с разрядкой.** Тринадцать правил с `text-transform:uppercase` и разрядкой .06–.24em (eyebrow, «for Windows», «uptime», подпись осциллографа, заголовок симулятора, шапка таблицы, подсказка глобуса, заголовки подвала, термины требований, плашка аварии, «Летим внутрь», номера карточек, крошки) — теперь обычный регистр и .02–.04em. Надписи капсом в разметке и на canvas («FAIL-CLOSED», «ЛЕТИМ ВНУТРЬ», «ТУННЕЛЬ УПАЛ», «WFP · BLOCK») и подпись в `og.png` — тоже.
- **Сетка отступов.** 79 значений padding / margin / gap вне сетки 4 px (14, 18, 22, 26, 34, 58, 70 и т. п.) переведены на сетку. Оставлены по правилам прохода: зазор 10 px между иконкой и подписью, шаги по 2 px внутри мелких контролов, оптические сдвиги на 3 px.
- **Значок над заголовком.** Рамка с плашкой версии стала тихой текстовой ссылкой «2.0.0 Windows · Rust · sing-box и Xray».
- **Непроверяемые утверждения и общие слова.** Сравнение с «типичным VPN-клиентом» заменено сравнением двух режимов клиента, обещание «без телеметрии» убрано, заголовок «Умные правила, понятные людям» стал «Что напрямую, а что через туннель», плейсхолдер поиска стал коротким, «Fail-closed во всей красе» на 404 убрано.
- Восклицательных знаков, слов-хайпа и градиентного текста не нашлось (`.grad` уже был сплошным цветом).

Оставлено намеренно: свет в точке схода туннеля (часть сцены пролёта, а не подложка под текст), пульсирующее кольцо статуса на демо-пульте и мигание точки на плашке аварии (это живые состояния демо), полосы на рубильнике.

Предложения, не применённые в polish-режиме: оранжевый CTA-блок в конце страниц — самая большая заливка акцентом на сайте, её можно сделать тёмной с оранжевой кнопкой; цветные рамки у тегов статуса можно приглушить до волосяных линий.

Заодно: таблица режимов на главной на телефоне прокручивается с шириной от 640 px, а не сжимается в столбик слов; `tools/serve.mjs` слушает только `127.0.0.1`. После прохода 12.11.2026 зелёные `npm test` (3 из 3), `npm run build`, `node tools/lint-html.mjs` и `node tools/check.mjs` (42 из 42: рубильник, пролёт, аварийный режим, якорь, 9 страниц на 1440, 1024, 768 и 390 px).
