Для разработчиков

Соберите из исходников

Нужны Rust 1.99 (MSVC, через rustup) и WebView2 Runtime. NSIS cargo xtask скачивает сам, Node.js клиенту не нужен.

PowerShell
# клонирование
git clone https://github.com/newnout6-a11y/vpn.git
cd vpn/vpn-tunnel-enforcer

# закреплённые движки: скачать и сверить SHA-256
cargo xtask engines
cargo xtask verify

# установщик, переносной архив и checksums.txt в target/dist/
cargo xtask dist
  • {{icon:check|icon}}Движки скачиваются сами. cargo xtask engines берёт sing-box 1.14.4, Xray 26.11.9 и Wintun 0.14.1 по адресам и SHA-256 из resources/engines.toml.
  • {{icon:check|icon}}Запуск из исходников. cargo run -p vpnte-app с абсолютным путём к resources/ в VPNTE_RESOURCES_DIR. Чтобы не трогать свои данные, укажите отдельную папку в VPNTE_DATA_DIR.
  • {{icon:triangle-alert|icon}}Не все тесты идут локально. cargo test --workspace пропускает группы elevated_* и system_*: им нужны права администратора или реальные настройки пользователя, их запускает CI.
Первый запуск

Три шага до защиты

{{icon:key-round|icon}}

1. Добавьте ключ

Вставьте подписку или ключ. Проверка ключа запустит временный движок, прокачает 64 КиБ через сервер и покажет вердикт с причиной.

{{icon:gauge|icon}}

2. Выберите режим

Без прав первый запуск выбирает «Прокси». Для «Туннеля» запустите приложение от имени администратора: само оно права не попросит.

{{icon:shield-check|icon}}

3. Проверьте утечки

Проверка IP и утечек покажет, что идёт через VPN. В «Прокси» она же скажет, если WebRTC может выдать реальный адрес.
