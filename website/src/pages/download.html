Соберите из исходников

Если вы хотите попробовать уже сейчас, клиент собирается локально. Нужен Node.js 22.13+.

PowerShell
# клонирование и запуск в режиме разработки
git clone https://github.com/newnout6-a11y/vpn.git
cd vpn/vpn-tunnel-enforcer
npm install
npm run dev

# установщик Windows (NSIS)
npm run dist:win
  • {{icon:check|icon}}Откройте окно Electron, а не адрес Vite в браузере: интерфейс использует типизированный мост contextBridge.
  • {{icon:triangle-alert|icon}}Бинарники нужно добавить вручную. В репозитории нет sing-box.exe, xray.exe, wintun.dll и libcronet.dll. Положите их в resources/ до сборки.
  • {{icon:triangle-alert|icon}}Rust-сайдкар опционален. Без cargo в установщик попадёт только PowerShell-фолбэк, он опрашивает журнал событий и на части систем теряет события.
Первый запуск

Три шага до защиты

{{icon:key-round|icon}}

1. Добавьте ключ

Вставьте подписку или ключ любого поддерживаемого протокола. Клиент проверит его в изолированном ядре.

{{icon:gauge|icon}}

2. Planner подскажет режим

Connection Planner проверит систему и порекомендует Hard или Soft Mode.

{{icon:shield-check|icon}}

3. Запустите self-test

Проверка на утечки покажет, остаётся ли физический адаптер заблокированным.
