Переписывание на Rust: клиент 2.0.0

2.0.0в коде · 12.11.2026

Один исполняемый файл на Rust (редакция 2024, rustc 1.99) с интерфейсом Dioxus 0.7.10 в WebView2: без IPC-слоя, Node.js, PowerShell и вспомогательных скриптов. Движки sing-box 1.14.4 и Xray 26.11.9 — дочерние процессы. Код старого клиента удалён, его данные импортируются один раз.

  • 15 крейтов, у каждого свой API.md
  • 2751 тест пройден локально, 0 упало, 31 пропущен (12.11.2026)
  • Движок выбирается явно: «авто», sing-box или Xray

Работа без прав администратора

решение владельца · 11.11.2026в коде

«Прокси» — режим по умолчанию и без прав. «Туннель» и kill switch на WFP — только когда приложение запущено от имени администратора, без самоповышения и UAC. Установщик на пользователя и переносной архив тоже обходятся без прав.

Служба-помощник

решение владельца · 12.11.2026в работе

Служба даст «Туннель» и kill switch без запуска приложения от имени администратора. Её ставит установщик, Windows один раз спрашивает разрешение; если его не дать, работает «Прокси». Ядро службы написано, к приложению и установщику она пока не подключена.
